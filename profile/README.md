# Adarium Labs

Open-source Ada/SPARK libraries and tooling, formally verified where it matters.

Founded by Quentin Dauprat, PhD in static analysis of Ada. Our code is written for people who ship safety-critical or high-integrity software, and for anyone who wants Ada libraries with clear contracts.

## Libraries

| Crate | What it does |
|---|---|
| [distance](https://github.com/adarium-labs/distance) | Distance and similarity metrics, proven free of runtime errors with SPARK. **SPARK Crate of the Year 2025 (AdaCore).** |
| [spark_math](https://github.com/adarium-labs/spark_math) | Formally verified math library in SPARK. |
| [termicap](https://github.com/adarium-labs/termicap) | Terminal capability detection: TTY, color, size, Unicode, terminal identity. |
| [anystring](https://github.com/adarium-labs/anystring) | Generic string abstraction, selected at build time. |
| [radix_literals](https://github.com/adarium-labs/radix_literals) | Parse hex, octal, binary and based numeric literals. |

The `distance`, `spark_math` and `termicap` crates are available through [Alire](https://alire.ada.dev).
